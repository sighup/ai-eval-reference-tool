# Changing or Cancelling an Order

An order can be cancelled at no cost while it is still processing. Once the
carrier has scanned the parcel the order has shipped and can no longer be
cancelled; at that point the customer should refuse delivery or start a return.

Delivery addresses can be corrected while the order is processing. After
shipment, an address change has to be arranged with the carrier using the
tracking number, and Northwind Goods cannot guarantee it will be applied.

Item quantities and sizes cannot be changed after checkout. The customer should
cancel the order if it is still processing and place a new one, or return the
item once it arrives.
