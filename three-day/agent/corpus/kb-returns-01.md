# Standard Return Window

Most items purchased from Northwind Goods may be returned within 30 days of the
order date for a full refund to the original payment method. The 30-day clock
starts on the date the order was placed, not the date it was delivered.

To be eligible, an item must be unused, in its original packaging, and include
any tags or accessories that shipped with it. Return shipping is free for
domestic orders; the customer pays return shipping on international orders.

Orders placed more than 30 days ago are outside the standard return window and
are not eligible for a refund under this policy. Agents should tell the customer
the order date, state how many days have passed, and explain that the window has
closed. Do not issue a refund for an order outside the window.
